대화와 실행 기록

초기화해도 세션 호출 한도와 기록은 유지됩니다.

선택 문서 전체 요약

문서 하나를 선택하고 ‘선택 적용’을 누르세요. 전체 원문을 나누어 읽고 사업 개요·예산·기간·자격·제출 조건·평가 기준을 정리합니다.

문서를 선택하면 예상 호출 수를 확인할 수 있습니다. 선택만으로는 API를 호출하지 않습니다.

생성하려면 왼쪽에서 실제 API 답변·요약 생성을 켜고 선택 문서 API 설정을 적용하세요.
