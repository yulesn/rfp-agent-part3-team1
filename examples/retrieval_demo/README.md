# 검색 연결 확인용 예제

이 폴더의 기관·사업·금액은 실행 확인을 위해 만든 가상 자료입니다. 실제 RFP에서 가져온 내용이 아닙니다.

- `chunks.jsonl`: 본문과 metadata가 있는 문서 3건. 각 문서를 한 청크로 제공합니다.
- `questions.jsonl`: 기대한 문서와 근거 문장. `max_rank: 1`은 1순위에서 근거를 찾아야 한다는 뜻입니다.

파싱·청킹 품질을 평가하는 데이터가 아닙니다. 실제 OpenAI 임베딩과 DB 저장·재접속·검색 연결을 확인합니다.
생성한 DB와 보고서는 Git에서 제외되는 `data/`에 저장합니다. 팀 전체 DB와도 경로를 분리합니다.

실행 순서는 [검색 가이드](../../docs/retrieval.md)를 참고하세요.
